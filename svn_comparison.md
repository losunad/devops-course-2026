# Сравнение Git и SVN

## 1. Почему в Git ветвление «дешёвое», а в SVN — «дорогое»?

Git является распределённой системой контроля версий. Ветки создаются локально и представляют собой лёгкие указатели на коммиты, поэтому создание и переключение между ними выполняется быстро.

SVN является централизованной системой контроля версий. Ветвление связано с созданием копий директорий в центральном репозитории и сильнее зависит от сервера.

## 2. Можно ли в SVN сделать коммит без интернета? Почему?

Нет. Для выполнения обычного коммита в SVN необходимо соединение с центральным сервером, поскольку история версий хранится в центральном репозитории.

В Git коммиты создаются локально, поэтому подключение к интернету для создания коммита не требуется.

## 3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?

SVN может использоваться в существующих legacy-проектах, инфраструктура которых уже построена вокруг централизованной системы контроля версий.

Также SVN может применяться в организациях, где требуется централизованное управление репозиторием и доступом к его отдельным директориям.
