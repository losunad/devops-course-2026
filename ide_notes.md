# Git в VS Code

## Что удобно делать в VS Code

1. Удобно просматривать изменённые файлы через панель Source Control.
2. Можно визуально сравнивать изменения в файлах с помощью diff.
3. GitLens позволяет просматривать историю изменений и информацию о коммитах.

## Что удобнее делать в терминале

В терминале удобнее выполнять сложные Git-команды и контролировать процесс работы с ветками.
